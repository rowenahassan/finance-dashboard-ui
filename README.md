# Finance Dashboard UI

A responsive finance dashboard interface built using HTML and CSS Grid.

## Features

- Responsive dashboard layout
- CSS Grid-based structure
- RTL & Arabic UI support
- Sidebar navigation
- Tables, cards, and widgets
- Modern and clean design

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Font Awesome
